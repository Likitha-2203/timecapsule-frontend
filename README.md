# TimeCapsule Frontend

A React-based frontend for the TimeCapsule application, built using Vite.

## Features
- User registration and login
- Email verification
- Password recovery
- Create scheduled time capsules
- View and manage capsules
- Unlock messages when their scheduled date arrives

## Technologies Used
- React
- JavaScript
- CSS
- Vite

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Start the development server

```bash
npm run dev
```

### 3. Open the application

Open the local URL displayed in your terminal, usually `http://localhost:5173`.

## Backend

The frontend communicates with the TimeCapsule Spring Boot backend.
